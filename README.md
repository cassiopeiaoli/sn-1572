# SN-1572 Design Document

This document describes design and purpose of SN-1572 and mainly its
Visor Interface.

## Components Used:
- ATtiny85.
- a Gesture Detection Sensor Module that uses I2C communication protocol.
- A buzzer for sound generation.
- Touch/Pressure sensor.
- Tilt Sensor.
- 16x8 WS2812b LED Matrix.
- 3m 6800 visor.
